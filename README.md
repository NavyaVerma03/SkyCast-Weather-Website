# 🌈 About SkyCast

✨ SkyCast is a premium modern weather application built using:

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🧠 DOM Manipulation
- ☁️ Weather API

This project provides:

✔ Real-Time Weather Updates  
✔ Dynamic UI Effects  
✔ Responsive Design  
✔ Beautiful Weather Animations  
✔ Interactive User Experience

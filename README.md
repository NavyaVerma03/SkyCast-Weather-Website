# 🌈 About Project

## ✨ SkyCast Weather

SkyCast is a modern and interactive weather web application that provides real-time weather information with beautiful animations and premium UI effects.

This project is specially designed with:

- 🌦️ Dynamic Weather Effects
- ☁️ Animated Backgrounds
- ⚡ Fast Search System
- 📱 Responsive Layout
- 🎨 Glassmorphism Design
- 🌍 Real-Time Weather Data

# 🌍 SkyCast Weather Website

✨ **SkyCast Weather** is a beautiful and modern weather forecasting website that provides real-time weather updates for cities around the world.

This project is built using:

- ✅ HTML5
- ✅ CSS3
- ✅ JavaScript
- ✅ DOM Manipulation
- ✅ OpenWeather API

SkyCast Weather offers a clean user interface with smooth animations, responsive layout, and dynamic weather updates.

# 🔑 OpenWeather API Setup

## Step 1

Go to OpenWeather website:

```bash
https://openweathermap.org/api
```

---

## Step 2

Create your free account.

---

## Step 3

Generate your API key.

---

## Step 4

Replace API key inside `script.js`

```javascript
const apiKey = "YOUR_API_KEY";
```

---

# 💻 Example API Fetch Code

```javascript
async function getWeather(city){

  const apiKey = "YOUR_API_KEY";

  const url =
  `https://api.openweathermap.org/data/2.5/weather?q=${city}&units=metric&appid=${apiKey}`;

  const response = await fetch(url);

  const data = await response.json();

  console.log(data);

}
```
